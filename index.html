Asset Management System (AI-Assisted)

"Assets Assistant" on Google Gemini

The model only turns a question into predefined read-only intents and filters, validated against whitelists before use — with automatic fallback to a rule-based parser when the API fails. Chats keep session context for follow-up questions.

Security stays in code, not in the AI: permissions come from the JWT, purchase costs are admin-only, queries are parameterized EF Core, and the endpoint is rate-limited per user.

  • Hand-designed SQL Server schema, scaffolded with EF Core Database First, with Identity in a single DbContext.
  • Optimistic concurrency for asset updates/transfers and Redis caching with key invalidation on writes.
  • Asset transfers with full history tracking, and soft delete for assets, users and transfers.
  • Admin/User role management with a last-admin protection rule.
  • Rotating refresh tokens — only their SHA-256 hashes are stored, never plain text.
  • Angular front end with Guards, Interceptors, Signals and typed services, with separate Admin/User views.
  • MediatR handlers unit tested with xUnit and Moq.
